# Зависимости и распространение

Версии фиксируются в корневом и модульных `build.gradle.kts`, Gradle — в `gradle/wrapper/gradle-wrapper.properties`.

Основные компоненты: Kotlin 2.3.21, Compose 1.10.3, coroutines 1.10.2, serialization 1.9.0, Ktor 3.4.1 и JNA 5.18.1. JNA используется для macOS Keychain; системные frameworks предоставляет macOS. Иконка Chiller создана для проекта; генераторы ресурсов не являются runtime-зависимостями.

Этот список не является полным SBOM или проверкой лицензий транзитивных зависимостей. Перед публичным распространением бинарников нужно проверить комплект лицензий/NOTICE для фактически включённых библиотек и runtime. Для JNA в проекте выбран вариант Apache-2.0 из двойного лицензирования; upstream-уведомления необходимо сохранить.

Chiller распространяется под [Apache License 2.0](../LICENSE). Она не заменяет лицензии сторонних компонентов. Текст лицензии Chiller включается в ресурсы приложения и передаётся сборщику установщиков.

## Встроенный ripgrep

Установщик содержит ripgrep 14.1.1 из официального релиза BurntSushi/ripgrep. Архив выбирается по ОС и архитектуре сборки, SHA-256 фиксирован в `build-support/ripgrep.gradle.kts`. Вместе с бинарником поставляются COPYING, LICENSE-MIT и UNLICENSE из архива. Chiller использует вариант MIT. При запуске приложение ничего не скачивает; обновление бинарника выполняется через новую сборку. Windows ARM64 пока не поддерживается этой упаковкой.
