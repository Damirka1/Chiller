# Сайт Chiller

[English](README.md) · **Русский**

Статический лендинг на Astro, Tailwind CSS и TypeScript. Английский по умолчанию: `/Chiller/`; русский: `/Chiller/ru/`. Без backend, аналитики, внешних шрифтов и запросов к моделям. Скриншоты пока показывают русский интерфейс независимо от языка сайта.

## Локальный запуск

Нужны Node 24 (проверено с 24.14.1) и npm:

```sh
cd website
npm ci
npm run dev
```

Откройте напечатанный адрес с путём `/Chiller/`. Production-сборка: `npm run build`, просмотр: `npm run preview`. Не открывайте `dist/index.html` напрямую: базовые пути GitHub Pages требуют HTTP-сервер.

## Проверка

```sh
npm run build
npm test
```

Локальные тесты используют установленный Google Chrome. CI использует Chromium из Playwright (`npx playwright install --with-deps chromium`, затем `CI=true npm test`). Проверяются оба языка на ширинах 320, 390, 768 и 1440 px, переключение скриншотов, просмотр в диалоге, мобильное меню, языковые ссылки, загрузка картинок, ошибки браузера, уменьшение движения и автоматические проверки WCAG. Скриншоты страниц сохраняются в `test-results/`. Автоматические проверки не заменяют ручную проверку со скринридером.

## GitHub Pages

Workflow `.github/workflows/website.yml` запускается **только вручную**. Публикация выполняется при выбранном `publish` и только с ветки `master`, после сборки и тестов. Создание файлов не публикует сайт и не меняет настройки репозитория.

1. Включите сайт и workflow в `master`.
2. В Settings → Pages репозитория выберите источник **GitHub Actions**.
3. В Actions запустите **Website · GitHub Pages** с выбранным `publish`.

Ожидаемый адрес после успешной публикации: `https://Damirka1.github.io/Chiller/`. Это настроенный адрес, а не подтверждение доступности сайта. Домен и базовый путь задаются в `astro.config.mjs`; при изменении также обновите URL шрифтов, браузерные тесты и инструкцию.

## Редактирование

- `src/content.ts`: тексты на двух языках; обновляйте вместе.
- `src/components/Landing.astro`: общая разметка и метаданные.
- `src/styles/global.css`: оформление, адаптивность и уменьшение движения.
- `src/scripts/site.ts`: меню, переключатель скриншотов и нативный диалог просмотра.
- `src/assets/`: скриншоты из `docs/images` и согласованная иконка Chiller. При необходимости замените новыми снимками приложения. Astro оптимизирует изображения в WebP при сборке.
- `public/fonts/`: локальные шрифты Medeo с лицензией SIL OFL.

Описание возможностей основано на README проекта. Демо-снимки явно обозначены. Ссылки скачивания ведут в GitHub Releases без предположений об имени установщика или последней версии.

## Зависимости и лицензии

Версии закреплены в `package.json` и `package-lock.json`: Astro 7.4.4 (MIT), Tailwind CSS и Vite-плагин 4.3.3 (MIT), Playwright Test 1.64.1 (Apache-2.0), интеграция axe-core с Playwright 4.14.0 (MPL-2.0; только разработка). Medeo — SIL OFL 1.1, см. `public/fonts/OFL.txt`. Код сайта использует Apache-2.0 репозитория. Дополнительные стоковые изображения и логотипы сторонних брендов не используются.
