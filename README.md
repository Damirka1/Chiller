# Chiller

Desktop coding agent на Kotlin/JVM и Compose Desktop. Точные инструменты, экономный контекст и минималистичный интерфейс с режимами Focus и Studio.

**Текущий статус:** рабочий desktop-прототип, частичная alpha. Десять модулей, Focus/Studio, файловое ядро, 12 инструментов, процессы, журнал, адаптер DeepSeek. Актуальная матрица «сделано / частично / не проверено» — в [STATUS](docs/STATUS.md); подробности последнего прогона — в [RUN_REPORT](docs/RUN_REPORT.md).

Основная ветка Git: `master`.

Дизайн и основное направление согласованы 16 октября 2026 года. Первый доступный провайдер разработки — DeepSeek V4.1 Flash (`deepseek-flash`). Gemma 4 26B-A4B через vLLM остаётся целевой моделью; live-проверка отложена до доступа к серверу.

## Ключи и локальные данные

API-ключ не вставлять в репозиторий, документацию, тестовые fixtures или сообщения субагентов. Для первого opt-in live test предполагается переменная `DEEPSEEK_API_KEY`, затем хранилище секретов ОС / ввод на время сессии в приложении. Общие тесты выполняются без ключа через FakeProvider и fixtures. Отсутствие ключа не должно блокировать сборку и разработку UI.

## Сборка и запуск

JDK 21+ (текущая проверка на JDK 26), Gradle 9.4.0 через wrapper, Kotlin 2.3.21, Compose 1.10.3. Для файлового поиска нужен `rg` на PATH; сквозной offline smoke также использует Python 3. Первый запуск скачивает JVM/Compose-зависимости, включая нативный runtime текущей ОС.

```sh
./gradlew check :evals:offlineSmoke
./gradlew :evals:liveDeepSeekSmoke   # opt-in, нужен ключ и небольшой бюджет
./gradlew :app-desktop:run
```

В приложении выберите папку проекта, настройте URL/model/API key. Ключ из UI хранится только в памяти. Без ключа доступен явно обозначенный offline-режим; он не выполняет задачи пользователя с файлами. По умолчанию выбран Plan. Изменения файлов разрешаются в Workspace edit, запуск команд — отдельным переключателем; это не OS sandbox.

По умолчанию данные приложения сохраняются в `~/.chiller`; `CHILLER_DATA_DIR` позволяет выбрать отдельную папку. В настройках на диск записываются URL/model/workspace, но не ключ. Для изолированного просмотра:

```sh
CHILLER_DATA_DIR="$PWD/.chiller/local" ./gradlew :app-desktop:run -PchillerPreview=true
```

Общий `check` не использует удалённую модель. `offlineSmoke` выполняет scripted model loop с настоящими файловыми операциями, Python-проверками и восстановлением журнала. Live DeepSeek/Gemma пока не подтверждены. Установка и упаковка на Windows/Linux ещё не проверялись.

В меню «Файл» доступны экспорт Markdown/JSON с предпросмотром и выбор рабочей папки через системный диалог. Экспорт скрывает известные поля секретов и приватное replay-содержимое; произвольный текст следует проверить вручную. Файлы артефактов представлены ссылками, а не встроенными копиями.

Контекст ограничивается целыми ходами пользователя с сохранением пар вызовов/результатов инструментов. Старые крупные tool-результаты под давлением заменяются короткой заглушкой, а не выбрасываются вместе с ходом. Оценка токенов приблизительная (символы/4), это не счётчик провайдера; фактический usage приходит от провайдера и пишется в `run.summary`.

Инструменты спроектированы под минимум раундов: `read_file` отдаёт `snapshot_id`, успешный `edit_file` возвращает `snapshotId` новой версии, поэтому повторные правки одного файла не требуют перечитывания; независимые READ-вызовы выполняются параллельно, а эффекты — строго по порядку; `search_text` отдаёт компактные `path:line` с опциональным контекстом. `run.summary` в журнале фиксирует раунды, число и ошибки tool-вызовов, время и токены — по нему измеряется скорость, а не по ощущениям.

При запуске из корня репозитория приложение читает `API_TOKEN` из локального `.env` (также поддерживается `DEEPSEEK_API_KEY`). Переменные окружения имеют приоритет над файлом. `.env` исключён из Git. Файл читается при запуске; после изменения перезапустите приложение. При запуске через Finder рабочая папка может отличаться: для `.env` используйте команду Gradle из корня проекта. Ключ, введённый через настройки UI, остаётся только в памяти до закрытия.

Флаг `-PchillerPreview=true` собирает отдельный `ChillerPreview.app` и полностью отключает автоматическую загрузку ключа при запуске — для безопасной визуальной проверки. Обычная сборка: `./gradlew :app-desktop:createDistributable`.

В ответах сохраняется автор модели; старые сообщения имеют нейтральную подпись, offline — отдельную. Доступны меню моделей и истории, переименование, экспорт выбранного диалога, обычная/компактная плотность и постоянные настройки вида. Кнопка проверки подключения выполняет один ограниченный запрос только по нажатию; наличие ключа само по себе не означает проверенное соединение. При смене адреса провайдера ключ для другого origin нужно задать явно.

Повторяемые макеты и фактическая приёмка: [UI_ACCEPTANCE.md](docs/UI_ACCEPTANCE.md).
